# 標識よみ

道路標識を見て意味を当てる、意味を読んで標識を選ぶ、1日5問のゲーム。時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/hyoshiki-yomi/
- 問題は2通り：標識の絵を見て意味を4つから選ぶ／意味を読んで標識を4つの絵から選ぶ。まちがえても選び直せます。
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも・警戒・規制・指示を選べる）、とことん（まちがえても続く・好きなだけ）、当てた標識が集まる「標識帳」（64枚）があります。
- ヒントは「標識の種類（形と色のきまり）を言う」→「選び肢を2つにしぼる」の2段です。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、機種を変えるときの「引き継ぎ」があります。

## 出どころ

標識の名前・番号・意味は「道路標識、区画線及び道路標示に関する命令」（標識令）の別表第一、絵は別表第二の様式を見て簡単にかき直したものです。意味はやさしい言葉に言いかえています。

- e-Gov 法令検索「道路標識、区画線及び道路標示に関する命令」： <https://laws.e-gov.go.jp/law/335M50004002003>（2026-11-07 に e-Gov 法令 API で別表第一の本文と別表第二の図を確認）
- 駐車と停車のちがい：e-Gov 法令検索「道路交通法」第2条： <https://laws.e-gov.go.jp/law/335AC0000000105>

絵の色や大きさは実物と同じではなく、数字（重さ・高さ・速さなど）は一例です。標識の下の補助標識で、時間や車の種類によって決まりが変わることがあります。このゲームは標識に親しむためのもので、運転免許の勉強や正式な説明の代わりにはなりません。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を使うと、ページを開くたびに Google へつなぐことがあり、そのとき IP アドレスが Google に届きます。「X」「LINE」「ほかのアプリで送る」を押したときだけ、結果の文が選んだ先に渡ります（標識と答えは入りません）。

